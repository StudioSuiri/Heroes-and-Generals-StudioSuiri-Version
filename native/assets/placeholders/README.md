# Generic placeholder assets

The current client draws its arena, capture zone and soldiers as simple shapes. No proprietary Heroes & Generals art, sound, model, map or extracted game resource is included.

Future generic packs can be placed in soldier/, terrain/, vehicle/, ui/, and audio/ subdirectories. Use generic silhouettes or low-poly test models, ground/road/cover tiles, a generic transport and armored silhouette, native icons, a crosshair, and self-authored or permissively licensed test sounds.

Before adding any collection, create an asset manifest recording the source, license, attribution, hash, redistribution rights and planned replacement. A source-code license does not automatically license game-owned art.
